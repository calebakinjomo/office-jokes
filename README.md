## The joke

> I told my boss I was drowning in work. He sent a calendar invite: 'Swimming Lessons.'

One line, 85 characters. A setup every office worker recognises — "drowning in
work" — and a turn nobody sees coming: the boss takes the metaphor literally
and answers the only way a manager knows how, with a calendar invite.

## How it works

`main.py` is a small deterministic program (Python 3.13, no network, no clock,
no randomness, no environment reads) that writes the joke to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
